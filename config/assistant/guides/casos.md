## Para qué sirve
Un caso es todo lo que se trabaja con un cliente: una oportunidad de venta (Ventas) o un caso de servicio como soporte, orden de trabajo o proyecto (Servicio). Cada caso tiene folio, etapa, responsable, tareas, conversaciones y su actividad.

## Dónde está
- Ventas › Oportunidades: los casos comerciales.
- Servicio › Casos: los de soporte, órdenes y proyectos.
Dentro se elige cómo verlos: Lista, Tablero (por etapas) o Dashboard. La opción recuerda la última vista que usaste.

## Crear un caso
1. Entra a Ventas › Oportunidades o Servicio › Casos.
2. Pulsa «Crear caso».
3. Elige el tipo, el contacto y escribe el título (en oportunidades también monto y cierre estimado).
4. Guarda. También puedes pedírselo al asistente: «crea una oportunidad para Acme por 50 mil».

## Dentro del caso
- Pestañas: Actividad (todo lo que ha pasado, con filtros Todo / Cliente / Notas / Tareas / Cambios), Pendientes (Tareas y Tareas agendadas), Conversación, y «Más ▾» con el resto.
- Botones siempre a la vista: Nota, Tarea, Agendar y Mensaje, y «Conversaciones N ▾» para ligar o quitar conversaciones (un caso puede tener varias; los correos llegan como conversaciones).
- Oportunidad: los datos comerciales van en una línea con lápiz para editarlos; «Ganada» y «Perdida» están a la vista; Cancelar, Posponer y Cambiar estado están en «⋯».

## Mover, ganar, perder, posponer
1. Mover de etapa: arrastra la tarjeta en el Tablero o cámbiala en el caso. Mover de etapa no cierra ni pospone.
2. Ganar o perder: botón «Ganada» o «Perdida» y elige el motivo. Si hay más de una cotización abierta, al ganar se elige cuál aceptó el cliente.
3. Posponer: «⋯» › Posponer, con fecha y motivo. Se retoma después.
4. Al cerrar o cancelar con tareas pendientes, se pregunta qué hacer con ellas: cancelarlas, conservarlas sin caso o concluirlas con su reporte.

## Dudas frecuentes
- ¿Cómo reabro un caso cerrado? Con el botón «Reabrir» y un motivo. Solo administrador o supervisor.
- ¿Dónde se configuran tipos, etapas y motivos? Catálogos › Tipos de caso y Catálogos › Motivos de cierre (administrador).
- Servicio en campo: Servicio › Despacho (el día de los técnicos) y Servicio › Mantenimientos (los recurrentes de todos los clientes).
- Solo ves los casos que tu rol permite (todos o solo los tuyos).
