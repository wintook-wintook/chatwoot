## Cómo probar en browser

- Usuario admin de la cuenta de pruebas (account_id=2): `admin@kontrolya.com` / `TestLogin123!` (password cambiada durante testing).
- Webpack dev server en `:3035`, Rails en `:3000`. Para forzar recompilación si HMR no detecta cambios: `touch` el archivo.
- Chrome para screenshots: `/root/.cache/puppeteer/chrome/linux-131.0.6778.204/chrome-linux64/chrome` con `puppeteer-core` instalado en `/tmp/node_modules`.
